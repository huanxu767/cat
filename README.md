# 年薪百万 - 职业发展规划小程序

一款专业的职业发展规划微信小程序，帮助用户制定和追踪职业目标，实现薪资增长梦想。

## 功能特色

### 🎯 核心功能
- **薪资目标设定**：设置当前薪资和目标薪资，可视化进度追踪
- **职业规划**：制定详细的职业发展路径和里程碑
- **技能评估**：评估当前技能水平，获得个性化提升建议
- **学习计划**：制定学习计划，追踪学习进度
- **进度追踪**：多维度进度展示，成就系统激励
- **资源推荐**：精选学习资源和工具推荐

### 💰 广告变现功能
- **Banner广告**：页面底部横幅广告，用户体验友好
- **激励视频广告**：观看视频获得积分奖励，解锁高级功能
- **插屏广告**：在特定操作后展示，控制频率避免打扰
- **会员系统**：付费去除广告，解锁所有高级功能

## 广告集成说明

### 广告类型
1. **Banner广告**
   - 位置：页面底部
   - 展示时机：页面加载3秒后自动显示
   - 尺寸：自适应屏幕宽度

2. **激励视频广告**
   - 触发方式：用户主动点击观看
   - 奖励机制：观看完整视频获得50积分
   - 功能解锁：临时解锁高级功能24小时

3. **插屏广告**
   - 展示时机：特定操作后（如快速规划功能）
   - 频率控制：最小间隔60秒
   - 用户体验：不影响核心功能使用

### 广告配置
```javascript
// 广告位ID配置（需要在微信广告后台申请）
adConfig: {
  bannerAdUnitId: 'adunit-2693364c5e8e2ac5',      // Banner广告位
  rewardedVideoAdUnitId: 'adunit-c893364c5e8e2ac5', // 激励视频广告位
  interstitialAdUnitId: 'adunit-d893364c5e8e2ac5'   // 插屏广告位
}
```

### 使用方法
```javascript
const app = getApp()
const adManager = app.globalData.adManager

// 显示Banner广告
adManager.showBannerAd()

// 显示激励视频广告
adManager.showRewardedVideoAd(
  () => { /* 观看完成回调 */ },
  (error) => { /* 错误回调 */ }
)

// 显示插屏广告
adManager.showInterstitialAd()
```

## 快速开始

1. **克隆项目**
```bash
git clone [项目地址]
cd annual-million-salary
```

2. **配置广告位ID**
   - 在微信广告后台申请广告位
   - 更新 `utils/adManager.js` 中的广告位ID

3. **导入微信开发者工具**
   - 打开微信开发者工具
   - 选择导入项目
   - 填入项目目录和AppID

4. **预览和调试**
   - 点击预览生成二维码
   - 使用微信扫码在真机上测试

## 广告收益优化建议

### 1. 用户体验优先
- 合理控制广告频率，避免过度打扰用户
- 提供有价值的激励，让用户主动观看广告
- 保持核心功能的流畅体验

### 2. 广告位置优化
- Banner广告放在页面底部，不遮挡主要内容
- 激励视频广告与功能解锁结合，提升观看意愿
- 插屏广告在自然的功能切换点展示

### 3. 数据分析
- 监控广告点击率和转化率
- 分析用户行为，优化广告展示策略
- 定期调整广告位和展示逻辑
